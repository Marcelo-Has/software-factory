# factory/checklists/

## Contract

Deterministic operating checklists — definition-of-done, gate checklists, milestone
gates — land here as an **EVP2** deliverable.

This directory ships **empty** in the core (see the `.gitkeep`) and is never written to
per-product: it is factory material, immutable per project like the rest of `factory/`.
Product-specific state (e.g. a variety registry, roadmap progress) lives in
`project/state/`, not here.
